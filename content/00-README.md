## ٢ — دليل التركيب في 3 خطوات (لكل صفحة)

### الخطوة 1 — أنشئ الصفحة في ووردبريس

1. ادخل لوحة التحكم → **الصفحات → أضف صفحة جديدة**
2. الصق **العنوان** من رأس الملف (السطر `title:`)
3. في الشريط الجانبي → **رابط الصفحة (Slug)** → اكتب القيمة من الجدول أعلاه مثل `about-egr` (بدون مسافات، بحروف إنجليزية صغيرة)

### الخطوة 2 — انسخ المحتوى والصق

1. افتح ملف الـ Markdown المقابل على جهازك (مثل `01-about-egr.md`)
2. انسخ كل المحتوى **بعد** سطور الرأس `---` (من أول عنوان `#`)
3. الصق في محرر ووردبريس (Gutenberg). العناوين `##` تتحول تلقائياً إلى بلوكات Heading
4. مواضع الصور مكتوبة كـ `[صورة: ...]` — استبدل كل واحدة ببلوك **صورة** وارفع الملف المقترح من المجلد أدناه

### الخطوة 3 — انشر واربط بالقائمة

1. اضغط **نشر** → اعرض الصفحة للتأكد من التنسيق والـ RTL
2. اذهب إلى **المظهر → القوائم** وأضف الصفحة للقائمة الرئيسية (انظر قسم ٤)
3. كرر نفس الخطوات للصفحات الأربع — كل صفحة تأخذ أقل من 5 دقائق

## ٤ — كيف تربط القوائم (Header & Footer)

1. **القائمة الرئيسية (Header):** المظهر → القوائم → أنشئ قائمة "الرئيسية" → أضف الصفحات الأربع + الرئيسية → رتبها حسب خريطة الموقع `sitemap.md` → حدد موقع العرض **Primary Menu**
2. **قائمة الفوتر:** أنشئ قائمة ثانية "الفوتر" → أضف نفس الصفحات + روابط خارجية (فيسبوك، إنستغرام، district1-eg.com) كـ **روابط مخصصة** → موقع العرض **Footer Menu**
3. احفظ القائمة بعد كل تعديل — التغيير يظهر فوراً بدون كود

## ٦ — التوافق مع RTL / LTR (العربية + الإنجليزية)

- **العربية (افتراضي):** كل الصفحات مكتوبة بفصحى مع اتجاه RTL — ووردبريس يطبقه تلقائياً إذا لغة الموقع العربية. لا تعدل المحاذاة يدوياً.
- **الإنجليزية (/en/):** الموقع الرسمي يستخدم مسار `/en/home-real-estate/` — لإضافة النسخة الإنجليزية أنشئ صفحة ثانية بنفس Slug مضافاً له `-en` مثل `about-egr-en` وانسخ الترجمة، أو استخدم إضافة Polylang واربط كل صفحة عربية بمقابلها الإنجليزي.
- الخطوط والأرقام (01040022670، 3200م²) تبقى LTR داخل النص العربي — لا تعكسها.
